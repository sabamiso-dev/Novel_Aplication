# Novel_Aplication

クラウド小説執筆アプリ **Nola** の代替を、**月額費用ゼロ・ローカル完結・PWA** で自作するプロジェクト。

> 🔒 **完全に個人専用**。第三者への頒布・公開・サービス化は一切想定しない（自分の PC とスマホでのみ動かす）。
> ⚠ Status: **要件定義フェーズ**（コード未着手）。詳細は [`docs/requirements.md`](docs/requirements.md) を参照。

---

## なぜ作るか

- クラウド小説執筆アプリの月額費用をゼロにしたい
- 原稿データを自分の手元（IndexedDB / ローカル）に置きたい
- PC 主・スマホ副の両対応を、配布バイナリ無しで成立させたい

## 主な特徴（予定）

- 青空文庫記法（`|漢字《かんじ》` 等）のプレーンテキストを保存形式に採用
- 縦書き / 横書き切替、ルビ・傍点ツールバー、エディタ + プレビューの 2 ペイン
- 作品 / 章 / 話 の 3 階層管理、自動保存、スナップショット履歴
- キャラクター / 世界観・用語集 / プロット のメタデータ管理
- TXT / なろう貼付用 / EPUB 3 へのエクスポート
- 執筆統計（日次文字数・連続執筆日数）、全文検索・置換、zip バックアップ／復元、テーマ切替（Phase 2）
- 完全オフライン動作（PWA）、外部送信なし

## 技術スタック

| 種別 | 採用 |
| --- | --- |
| ビルド | Vite |
| UI | Svelte + TypeScript |
| ローカル DB | Dexie.js (IndexedDB) |
| スタイル | TailwindCSS |
| PWA | vite-plugin-pwa |
| 動作環境 | 自分の PC で `npm run dev` または静的ビルドを自分の端末でホスト（公開はしない） |

採用理由・不採用案（Tauri / Electron など）は要件定義書 §2 を参照。

## フェーズ

| Phase | 内容 |
| --- | --- |
| Phase 1 (MVP) | 作品管理 / エディタ / 自動保存 / メタデータ / エクスポート / 文字数 |
| Phase 2 | 統計 / 全文検索・置換 / zip バックアップ / テーマ |
| Phase 3 | 同期方式（手動 export / Drive API / Tailscale / Yjs+WebRTC）— 決定保留 |
